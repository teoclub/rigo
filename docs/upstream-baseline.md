## Upgrade policy

Rigo Core is pinned to an official DeepSeek Harness **release tag**, never to
an arbitrary commit, and **must not follow upstream `master` automatically**.
Every upgrade requires an explicit decision recorded here: a new official
release tag, its full commit SHA, and a re-run of
`bun scripts/port-upstream.ts <clone>` against the new baseline.
`bun run verify:baseline` fails when the pinned tag, commit SHA, or any
package row is missing or inconsistent.

## Verification

- `bun run verify:baseline` — validates the manifest above and re-checks the
  pinned tag against the repository (`git ls-remote`) and any local clone.
- `bun run audit:source` — finds unregistered local packages, missing
  manifest fields, license gaps, and KEEP rewrite drift.
- `bun run verify:packages` — confirms licenses and source provenance enter
  the release artifacts.
- `bun run verify:boundaries` — enforces the package dependency boundaries.
