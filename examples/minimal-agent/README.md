# 最小 AI 小机器人（给小朋友看的说明）

## 它是什么？

想象你有一只**小机器人**，它要帮你算数。它有三样东西：

- 🧠 **脑子**：会想事情的大模型。没有钥匙时，用一个“假脑子”，它照着剧本说话。
- 🧰 **玩具箱**：机器人能玩的玩具（工具）。这里只有一个“加法玩具”。
- 📓 **小本子**：记住刚才说过的话。

还有两个帮忙的东西：

- 📦 **大盒子**（`bootCore()`）：把脑子、玩具箱、小本子装在一起，玩完再合上。
- 🤖 **想一想、玩一玩、看结果、再想**：这个循环是机器人自己会做的，我们不用教它。

## 怎么玩？

```sh
bun run start
```

输出大概是这样：

```text
🙋 小朋友问：2 加 3 等于几？
🧰 机器人玩了加法玩具：{"a":2,"b":3} → {"sum":5}
🗣️ 机器人说：2 加 3 等于 5。
```

想问别的问题，就在后面写上：`bun run start 3 加 4 等于几？`

## 换成真脑子

设置下面这些环境变量，机器人就会用真的大模型（任何 OpenAI 兼容的接口都行，比如 DeepSeek）：

| 变量 | 意思 |
| --- | --- |
| `RIGO_LLM_BASE_URL` | 接口地址，比如 `https://api.example.com/v1` |
| `RIGO_LLM_API_KEY` | 钥匙（只在运行时读取，不会写进文件） |
| `RIGO_LLM_MODEL` | 模型名字，默认 `deepseek-chat` |
| `RIGO_LLM_PROVIDER` | 线路名字，默认 `openai` |

## 怎么加一个新玩具？

玩具就是 `index.ts` 里的 `addToy` 这样的一个对象：

1. 起个名字（`name`），告诉机器人这个玩具叫什么。
2. 写一句话说明（`description`），告诉它这个玩具能干什么。
3. 写清楚要什么东西（`parameters`），比如要两个数字 `a` 和 `b`。
4. 写好怎么玩（`execute`），返回结果。
5. 用 `handle.ctx.tools.register(...)` 把它放进玩具箱。

## 怎么加一个新积木？

需要什么能力，就把对应的积木拿过来（加依赖），不需要的就不拿。积木都在 `packages/harness/` 里，比如：

- `harness-llm-openai-compatible`：真脑子的接线
- `harness-llm-mock`：假脑子
- `harness-tools`：玩具箱
- `harness-session`：小本子
